# The Design Index

A hand-kept index of website and app templates. Every entry is a single
self-contained HTML file: one page, no build step, no dependencies. Preview it,
download it, use it as a starting point. Everything is public domain.

![License: CC0 1.0](https://img.shields.io/badge/license-CC0%201.0-black)

## Useful info

Templates are grouped into categories: online clothing stores, online shops,
portfolios, landing pages, dashboards, AI chat, messaging apps, and mobile apps.

Each template is a full, interactive page rather than a component. It makes no
network requests, so no CDNs, no webfonts, no hotlinked images. It works offline
and stays readable when you open the source.

The index is a static site. Nothing is stored, tracked, or fetched at request
time.
